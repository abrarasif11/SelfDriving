# 🚗 Self Driving — Introduction to Programming Language Lab Final Project

This project is a **Self-Driving Car Simulation** built using **Python** and **Pygame**.  
The car automatically follows a track by detecting pixel colors and adjusting direction.  
This project was developed as part of the **Programming Language Lab Final Project**.

--- 

## 📌 Features
- Autonomous car movement  
- Pixel-based camera detection  
- Automatic turns based on track  
- Real-time rendering with Pygame  
- Smooth simulation performance  

---

## 🛠 Technologies Used
- Python 3  
- Pygame
